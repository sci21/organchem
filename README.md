# Organic Chemistry Studio v0.5 — 300개 독립 데이터 문제

기존 v0.4의 동일한 내용 재질문을 제거했습니다. 생성물 100개는 서로 다른 반응물·생성물·조건 조합, 시약 70개는 서로 다른 시작/최종 구조 조합, IUPAC 40개는 서로 다른 구조식, EAS 30개는 서로 다른 치환기/반응 맥락, 방향족 30개는 서로 다른 구조식, 분광학 30개는 서로 다른 분자 구조를 사용합니다.

**학술적 한계:** 생성물 구조식은 RDKit을 통해 유효한 분자식인지만 기계적으로 확인했으며 각 반응의 실험적 타당성과 모든 정답을 독립 전문가가 수작업 검수하지 않았습니다. 분광학 그래프는 원본 스펙트럼이 아닌 교육용 모식 신호이며, 특히 NMR은 진짜 피크 패턴/적분/다중성을 완전 재현하지 않습니다. 따라서 분광학 문제는 실제 구조결정 실습에 앞선 예비 연습용입니다.

`index.html`, `app.js`, `styles.css`를 GitHub Pages 저장소 루트에 올리세요. SmilesDrawer/Kekule.js CDN을 불러오기 위해 인터넷이 필요합니다. 기존 브라우저 기록은 유지되지만 문항 내용이 달라져 이전 오답 기록은 해당 새 문항에 연결될 수 있으니 초기화 후 사용을 권합니다.
